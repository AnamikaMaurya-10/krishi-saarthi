# Interactive UI Upgrade

This version keeps the same React + Express architecture and backend APIs.

Frontend upgrade:
- Smooth page/card entrance animations
- Hover and press micro-interactions
- Animated weather icon/orb
- Animated live indicator
- Animated onboarding progress bar
- Interactive onboarding option states
- Elevated dashboard cards and panels
- Animated risk score/factor bars
- Interactive officer alert cards and detail panel
- Responsive mobile styling
- Reduced-motion accessibility support

No Convex was added.
No new frontend dependency is required.

Run:
  cd backend
  npm install
  npm run dev

In another terminal:
  cd frontend
  npm install
  npm run dev
